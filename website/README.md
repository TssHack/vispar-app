# Vispar website

The landing page for Vispar, built with Next.js and exported as static files for GitHub Pages. Persian is at `/`, English at `/en/`.

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` writes the site to `out/`. The `Website` workflow builds and publishes it on every change to `website/` on `main`.

Copy lives in `content/dictionary.ts`; colours, type and spacing follow `../DESIGN.md`.
